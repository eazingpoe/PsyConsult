# 接入与安全检查清单

## 入库前

- [ ] `source_registry.csv` 中每个 source_id 都有有效的官方/原始来源。
- [ ] 具体药品内容已关联具体批准说明书（当前包未提供具体药品剂量资料）。
- [ ] 量表的中文版本、计分规则、许可状态已核实。
- [ ] 内容已由具备相应资质的专业人员审核；草稿状态未被误认为正式发布。
- [ ] 检查版权许可；公开可访问不等于可以任意复制或商用。

## 入库后

- [ ] 新集合与 `long_term_memory`、`cloud_product_docs` 分离。
- [ ] 记录集合名、embedding 模型、向量维度、文档版本和入库时间。
- [ ] 运行静态审计和检索评测。
- [ ] 随机抽查 20 条 Chunk，确认不是纯标题、重复段落或截断句子。
- [ ] 检查每条证据是否返回 `source_id`、`source_url`、`title` 和 `section_path`。

## 上线前

- [ ] 医学事实和风险提示经过人工审核。
- [ ] 无证据问题能清楚说明知识库限制，不伪造来源。
- [ ] 药物问题不提供个人化处方、剂量调整或停药方案。
- [ ] PHQ-9/GAD-7 解释明确说明筛查不等于诊断。
- [ ] 高风险自伤表达进入独立安全流程，未进入普通 Agent 或 RAG 回答流程。
- [ ] 地方热线、医院和服务时间经过本地核验。
- [ ] 日志与长期记忆遵循数据最小化原则，不记录不必要的敏感信息。
