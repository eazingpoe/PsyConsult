# 检索评测集说明

`retrieval_cases.jsonl` 包含 40 道初始检索问题，每行一个 JSON 对象：

- `case_id`：测试编号
- `query`：模拟用户问题
- `expected_source_ids`：预期应被检索到的来源 ID（任一命中即可计入 case hit）
- `expected_topic`：用于人工分组统计的主题标签

当前评测只测“预期来源是否进入 Top-k”，不测最终回答的医学正确性。上线前需要增加人工审核的参考答案、证据引用核对和高风险场景测试。对于药物安全和危机相关问题，不能只依赖 RAG 命中率判断安全性。
