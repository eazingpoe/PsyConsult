# PsyConsult 演示流程建议（约 3–5 分钟）

> 演示仅使用虚构测试用户和模拟报告，不要展示真实患者资料、真实报告、录音或 API 密钥。

## 0:00–0:30 项目介绍

介绍 PsyConsult 是一个心理健康科普与筛查辅助原型，主要包括对话问答、自评量表、患者档案、录音转写和测评报告分析。

## 0:30–1:15 心理健康问答

1. 输入一个低风险的一般性问题，例如“什么是睡眠卫生？请给出三条一般性建议”。
2. 展示流式回复。
3. 强调内容是科普，不是诊断。

## 1:15–2:00 心理健康自评

1. 打开心理健康自评页面。
2. 使用模拟答案完成 PHQ-9 或 GAD-7。
3. 展示分数、筛查用途说明和边界提示。
4. 不要把模拟分数解释为真实患者的诊断。

## 2:00–2:45 患者档案

1. 创建一个名称明显标注为“测试/虚构”的患者档案。
2. 展示基本资料、量表结果、历史记录和报告列表。
3. 说明档案用于功能验证；演示结束后清理测试记录。

## 2:45–3:45 报告分析

1. 上传明确标注为模拟数据的心理测评 PDF。
2. 展示文本提取和结构化解读结果。
3. 指出 OCR 可能出错，量表结果不能单独用于诊断。
4. 将报告归档到测试患者，展示报告与分析历史。

## 3:45–4:15 录音转写（可选）

1. 使用一句无敏感信息的测试语句。
2. 展示录音、转写结果。
3. 不要使用真实咨询录音。

## 4:15–5:00 技术与限制

简述 Vue 3 + TypeScript 前端、FastAPI 后端、LangGraph 工作流、知识检索、OCR 和 pytest 测试。最后说明：该系统是功能原型，尚未完成临床验证或生产级安全评估。
