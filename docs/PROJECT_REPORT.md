# PsyConsult 功能报告与测试结果

**报告性质：** 开发原型功能记录  
**测试记录日期：** 2026-10-20（来自开发过程中的终端输出）  
**重要限制：** 下列结果是历史记录，不代表当前仓库最新提交已自动复测，也不代表临床有效性或生产级安全性。

## 1. 项目概述

PsyConsult（心晴社区）是一个心理健康科普、筛查辅助与报告管理 Web 原型。系统将聊天问答、量表计分、患者档案、音频转写和测评报告辅助分析整合到一个工作流中。

## 2. 功能清单

| 模块 | 功能与验证范围 | 注意事项 |
|---|---|---|
| 对话问答 | 多轮问答、SSE 流式输出 | 依赖后端、模型服务与相关基础设施 |
| 安全支持 | 部分高风险表达安全分流与求助提示 | 不能替代危机评估或急救服务 |
| PHQ-9 | 计分、答案数量校验、第九题非零提示 | 筛查用途，不是诊断 |
| GAD-7 | 计分、答案数量校验 | 筛查用途，不是诊断 |
| 患者档案 | 基本资料、量表结果、历史记录、报告管理 | 公开演示只用虚构档案 |
| 录音转写 | 前端录音、后端转录接口 | 需确认音频限制和转录服务配置 |
| 测评报告分析 | PDF/DOCX/图片输入、文本提取/OCR、结构化解读 | OCR 和模型输出必须人工核对 |
| 报告归档 | 报告与患者档案关联、分析记录查询 | 开发过程中观察到归档可能耗时较长 |

## 4. 当前建议复测的发布门禁

每次准备发布时，在目标提交上重新执行：

```bash
python -m pytest -q app/test agent/test

cd front/clinical_cds
npm run build
```

再做人工回归：

- [ ] 普通问答完整返回，SSE 结束事件正常。
- [ ] PHQ-9 / GAD-7 正常计分，错误答案数量被拒绝。
- [ ] PHQ-9 第九题非零时出现安全提示。
- [ ] 患者档案创建、查看、修改、删除可用。
- [ ] 报告 PDF、DOCX 和图片上传、分析及归档可用。
- [ ] OCR 结果中的分数、日期、否定词和答案经人工核对。
- [ ] 录音转写可用，失败时有明确提示。
- [ ] 归档与历史记录没有串档。
- [ ] 使用虚构测试数据完成截图和演示。
- [ ] 当前文件与 Git 历史完成密钥扫描。
- [ ] 公开知识库中的每份材料都完成来源、许可和署名核对。

## 5. 已知限制与后续改进

1. **临床有效性未验证。** 自动化测试只检查软件行为，不能证明筛查解释、建议或危机识别具备临床有效性。
2. **报告分析需要人工复核。** OCR 可能把数字、否定词、日期或量表答案识别错误。
3. **归档耗时可能偏长。** 可后续检查是否在归档时重复调用模型，以及是否能复用已有分析结果。
4. **前端 bundle 较大。** 可考虑按页面懒加载和代码分包。
5. **依赖弃用警告。** 后续应评估 `langchain-community` 相关依赖迁移。
6. **生产安全尚需评估。** 应进一步完善认证、患者级授权、审计日志、加密、备份恢复和数据生命周期管理。

## 6. 适用边界

系统仅用于开发、演示和辅助沟通。不要将其作为独立诊断、处方或治疗决策工具；不要向公开演示环境上传真实患者资料。
