## 2. 运行本地文件审查

在仓库根目录执行：

```bash
python tools/audit_public_release.py
```

该脚本会列出常见敏感文件路径、疑似密钥的规则名称和行号，以及知识库材料的授权审查线索；不会主动打印匹配到的密钥值。它可能产生误报，也可能漏报，不能代替人工审查。

再使用 Gitleaks 扫描当前文件：

```bash
docker run --rm \
  -v "$PWD:/repo" \
  zricethezav/gitleaks:latest \
  dir /repo --redact
```

扫描 Git 历史：

```bash
docker run --rm \
  -v "$PWD:/repo" \
  zricethezav/gitleaks:latest \
  git --redact /repo
```

若发现真实凭据，先撤销或轮换凭据，再清理文件和历史。重写历史不能保证所有缓存、fork 或已克隆副本中的旧内容都消失。

- [ ] 没有真实 PHQ-9/GAD-7 答案、咨询记录、心理测评报告或上传附件。

如果公开仓库中存在真实患者信息，不要只删除当前文件就结束；还需评估 Git 历史、release、issue、构建产物和其他副本，并遵循适当的事件处理流程。

## 4. 知识库版权与再分发

仓库中如包含 `PsyConsult-community-kb-v1/knowledge_base/source_registry.csv`，应对其中每一条来源逐项核查。来源登记表能证明记录了来源信息，但**不能单独证明有权复制、改编或重新分发原文**。

建议为每一份材料建立以下记录：

| 字段 | 核查要求 |
|---|---|
| 原始来源 | 完整标题、发布机构、稳定 URL、访问日期 |
| 实际收录内容 | 仅来源链接、自己撰写的摘要、结构化事实，还是原文/整段翻译 |
| 许可 | 明确许可名称与版本，或书面授权记录；不能确认时标记“待核实” |
| 署名 | 按原来源要求保留作者、机构、标题、链接、日期及许可声明 |
| 第三方内容 | 图表、图片、量表、附录等是否另有权利人和独立许可 |
| 修改与翻译 | 是否属于改编/翻译，是否要求免责声明或相同方式共享 |
| 发布决定 | 可发布、仅保留链接、需要替换、待取得授权 |

### WHO 来源的特别注意

WHO 官网说明：部分 WHO 出版物适用特定 Creative Commons 许可，但不是所有网页内容和材料都自动适用相同许可；第三方内容可能需要单独取得授权。WHO 网站条款还区分一般引用/有限使用与大段复制、翻译或其他用途。

请逐条查看对应页面的版权声明和适用条款，不要因为 URL 来自 `who.int` 就默认整篇网页可复制进公开知识库。

官方参考：
- [WHO 版权、许可与授权](https://www.who.int/about/policies/publishing/copyright)
- [WHO 网站使用条款](https://www.who.int/about/policies/terms-of-use)
- [WHO 材料使用许可条款](https://www.who.int/about/policies/publishing/copyright/terms-and-conditions)

**保守做法：** 优先保留来源元数据、链接和自行撰写的简明事实摘要；未经核实不要把整篇网页、完整翻译、量表内容、图片或表格打包重新发布。
